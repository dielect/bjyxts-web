## 重绘目标

参考原版 NPC 的头部表现，同时让衣服、手脚和随身物件在小尺寸下可分辨。老叫花保留丐帮高手气概，摊主保留敦实的生意人形象；石桌区分棋盘线、棋子、桌沿和双桌腿。

## 审查重点与已知限制

- 生成稿采用像素风格，但没有严格遵守原生 32×32 网格；不能以大图清晰程度判断最终游戏效果。
- 本地试缩到 32×32 后仍存在部分细节粘连，需要继续检查头身比例、眉眼间隔、手脚轮廓、棍杖连续性及棋盘线。
- 此前透明底生成曾把部分黑色线条也抠除，因此最后一轮改为不透明游戏绿底预览。正式素材仍需处理透明边界，并保留不透明黑色轮廓。
- 目标配色为黑色与 #90B057，但原图仍可能有轻微色差、纹理或边缘过渡；正式导出应检查并归一化调色板。
- 本次只上传这三张最终绿底原图及说明、提示词，不包含失败的透明稿和未定稿的 32×32 试缩图。
