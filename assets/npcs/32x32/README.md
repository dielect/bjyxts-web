# 32×32 NPC 全身素材

> **游戏当前使用**（2026-10-05 起）：[old-beggar-v4-redraw.png](old-beggar-v4-redraw.png)、[staff-vendor-v3-redraw.png](staff-vendor-v3-redraw.png)。
> 由 `assets/reviews/crisp-redraw/` 的重绘稿自动缩成：裁掉留白后按区域采样缩到 32×32，深于灰度 110 的取黑色，被轮廓包住的部分填 #90B057，外面透明。未经手修，老叫花左侧头发有零散黑点、摊主腰部黑块偏大，可以在这两张上直接修改后用 `tools/make_npc_sprite.py` 重新生成。
> 下面是更早的版本说明。

| 人物 | 实际素材 |
| --- | --- |

两张素材均为实际 **32×32 像素 RGBA PNG**，保留完整身体与棍棒。可见颜色仅为原版黑色 `#000000`、橄榄绿 `#90B057`；透明度仅为 0 或 255，没有半透明边缘。四周留一像素透明边距。

[8 倍预览](preview-8x.png) 左侧为老叫花，右侧为棍棒摊主；使用最近邻放大，预览背景仅用于检查透明轮廓，不在实际素材中。

制作过程：使用内置 imagegen 简化全身造型（[提示词](prompts.md)），生成原图保存在 `sources/`。再裁掉外围透明留白，压缩到 30×30 人物区域并居中放入 32×32 画布，采用区域采样和双色归一化导出。透明覆盖阈值为 45%，绿色覆盖阈值为 65%，其余可见像素为黑色，以保留小尺寸线条。人物比例经过压缩，细小五官和衣纹有所简化。
