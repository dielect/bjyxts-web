> 状态：**第一、二批已实现**（2026-10-05）。第一批：引擎、全部 100 件装备的数据与特效、13 套套装、原版商店添货、六大门派军需官。第二批：江湖货郎、黑风寨、捕头相邀与六扇门差事、比武招亲（`src/game/mods/080_江湖奇遇二.rb`），另外君子剑改为行侠 5 次时在恶霸欺人里获赠，风火棍由山贼头目掉落。第三批（`src/game/mods/090_神兵与传闻.rb`）：江湖传闻追加 10 条、对应 9 处藏宝（倚天剑要打赢守剑老尼，金蛇剑硬闯掉三成气血）与剑冢（玄铁重剑，膂力天赋 25 或经验 200 万），逍遥故人、迷路的老婆婆、武当山脚的老道三段奇遇，老乞丐传完棒法后送丐帮衣物，客栈店小二卖酒葫芦。**三批全部完成，每件装备都有来源**（`tools/gear-test.mjs` 会检查）。藏宝位置与设计稿略有不同，以代码为准（倚天剑在大雪山西花园，天蚕丝鞭在红莲教大殿，混铁棍在平安镇南郊）。
> 实现时的调整：六扇门 4 件改为“缴械 15% + 减伤 10%”，丐帮 4 件只保留“天下无狗耗内力 -40%”，酒葫芦只保留回内；商店购买时顶栏显示商品描述和特效、套装标签。

> 原稿状态：设计稿，待确认后实现。已实现的第一批（武器 34～37、防具 32～38）见 `docs/内容设计思路.md` 3.5 节，本稿的编号接在它们后面：**武器 38～73（36 件）、防具 39～102（64 件）**。

## 0. 设计目标

1. **每个门派一套门派装备**，穿齐了强化本门武功：装备成为“走哪条路”的一部分，而不只是数值。
2. **江湖装备挂在选择上**：正派拿六扇门套，邪派拿黑风寨套，丐帮套要走完打狗棒法支线，神兵要靠传闻和奇遇去找。
3. **前期也有东西可买**：每个部位都有几件便宜的普通货，摆在原版商店里。
4. **数值守原作区间**：武器攻击不超过 99，防具防御不超过 60。要更强，靠特效和套装，不堆数值。

## 2. 特效一览

只对玩家生效。每件装备最多 1 个特效（神兵 2 个），套装效果另算。数字是设计初值，实现后按试玩调整。

### 2.1 兵器：普通攻击打中时

| 特效 | 效果 |
|---|---|
| 暴击 | 几率多打 X 倍伤害（已有） |
| 吸血 | 回复伤害 X% 的气血（已有） |
| 中毒 / 灼烧 | 几率让对方每次行动前失血，不致死（已有） |
| 点穴 | 几率定住对方（已有） |
| **破甲** | 按对方防御追加伤害：防御越高加得越多，最多 +40% |
| **吸内** | 回复伤害 X% 的内力 |
| **连击** | 几率顺势再打一下，威力减半 |
| **缴械** | 几率打落对方兵器（同原版落英缤纷，兵器归你） |
| **斩杀** | 对方气血低于 25% 时伤害 +X% |
| **迟滞** | 几率降低对方闪避，可叠加 |

### 2.2 防具：被打时 / 每回合

| 特效 | 效果 |
|---|---|
| 反震 / 护心 / 回春 | 已有 |
| **闪避** | 对方普通攻击 X% 直接落空 |
| **减伤** | 普通攻击伤害 -X% |
| **化劲** | 对方绝招伤害 -X% |
| **金刚** | 单次受伤不超过最大气血的 X% |
| **反击** | 被打中后 X% 几率还手一击（伤害为所受伤害的一半） |
| **回内** | 每次行动前回复 X% 内力 |
| **定心** | 不会被定身（用原版防具的“状态防御”字段，木鸡 1/2/19） |

### 2.3 武学加成（新）

| 特效 | 效果 |
|---|---|
| **武学威力** | 启用某门武功（或某门派的武功、或空手）时，普通攻击伤害 +X% |
| **武学精进** | 战斗中某门武功的等级视为 +N。只在战斗中生效，不改存档里的等级（不会触发原版的超限检查）。等级够了还能提前用出绝招 |
| **绝招省力** | 某些绝招耗内力 -X% |
| **门派共鸣** | 本人是某门派弟子时，效果加倍或额外加成 |
| **正气 / 邪气** | 道德 ≥ 200 / < 64 时才生效或额外加成 |

### 2.4 其他

| 特效 | 效果 |
|---|---|
| **神行** | 逃跑必定成功 |
| **财运** | 战斗所得银两 +X% |
