## 2. 封包解密

`Gmud.rgssad` 是 RGSSAD v1 格式，但**作者改过密钥递推公式**：

- 初始密钥仍是标准的 `0xDEADCAFE`
- 递推公式由标准的 `key = key*7 + 3` 改成了 **`key = key*7 + 9`**

所以通用解包工具会解出乱码。我先用已知明文 `Data\Actors.rxdata` 反推出这个参数，再用 `unrgssad.py` 一次解出全部 **153 个文件**：PNG 文件头和 Marshal 4.8 文件头都校验通过。

## 6. 网页移植的可行方案（建议）

因为这是标准 RMXP 游戏，脚本也已完整拿到，最接近"完美移植"的做法是**在浏览器里直接运行原版 Ruby 脚本**，而不是重写：

1. 使用 RMXP 的网页运行时（例如 mkxp 的 WebAssembly 移植版，或自行用 Emscripten 编译 mkxp），在浏览器中运行原版 `Scripts.rxdata`、地图和数据库。
2. 在 Ruby 层替换三个 Windows DLL：
   - `ActorNameSupport` → 改用网页输入框起名
   - `Background` → 直接移除
   - `NetworkSupport` → 你要求纯单机，所以关闭局域网对战入口
3. 存档：mkxp 网页版把文件系统映射到 IndexedDB，原版的 Save 文件可以直接存在本地浏览器里。
4. 音频：ogg 可以直接用；mp3 是否支持取决于运行时的编译选项，不支持就转成 ogg。
5. 字体：游戏需要黑体或宋体，打包一款可以自由分发的中文字体代替。

注意：上面这套运行时方案我还没有实际编译验证，需要先做一个可行性原型才能确认。

## 7. 交付文件

- `白金英雄坛说PC1.21_解包.zip`
  - `scripts/`：118 个 .rb 脚本（UTF-8，可直接阅读）
  - `rgss/`：解包后的 `Data/*.rxdata` 与 `Graphics/`
  - `unrgssad.py`：本游戏专用解包器（默认 `key*7+9`，可用环境变量 `RGSS_C=3` 切回标准公式）
  - `dump_scripts.rb`：Scripts.rxdata → .rb 导出器
