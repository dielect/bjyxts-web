## 技术路线
- ruby.wasm 2.10.1（@ruby/3.4-wasm-wasi ruby.wasm 16.6MB, brotli 3.1MB，含 zlib；Node 测 3M 循环 2.4s）
- 浏览器 WASI：@bjorn3/browser_wasi_shim 0.4.2（PreopenDirectory 内存 FS）；vm.evalAsync + JS await 让 Graphics.update 让出帧
- RPG 模块复用 mkxp-web extra/rgss.rb（https://github.com/pulsejet/mkxp-web, GPL-2.0），/home/ubuntu/mkxp-web
- mkxp 规则：tile z = 32*(y+prio+1)-oy；autotile 每16帧换帧（4帧, 帧宽96）；autotile 拼接表 src/autotiles.cpp（48*4 个 16x16 子块, 坐标去掉 .5）
- Window 皮肤：背景(0,0,128,128)拉伸到(2,2,w-4,h-4)；边框 l(128,16,16,32) r(176,16,16,32) t(144,0,32,16) b(144,48,32,16) 平铺；角 tl(128,0) tr(176,0) bl(128,48) br(176,48) 16x16；光标(128,64,32,32) 位置 cursor_rect+16；光标透明度表 0xFF→0x7F→0xF7 每帧-8；暂停图标 (160,64)(176,64)(160,80)(176,80) 位于 ((w-16)/2, h-16)；滚动箭头 l(144,24,8,16) r(168,24,8,16) t(152,16,16,8) b(152,40,16,8)；内容在 (16,16) 裁剪 w-32,h-32
- 工程目录：/home/ubuntu/rgssweb（npm: esbuild, @ruby/wasm-wasi, @bjorn3/browser_wasi_shim, @ruby/3.4-wasm-wasi）
